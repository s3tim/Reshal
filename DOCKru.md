# Reshal (Alpha) — Твой локальный ИИ-агент для терминала

Привет! Ты держишь в руках раннюю альфу **Reshal** — AI-агента, который понимает человеческий язык и выполняет задачи прямо в твоей операционной системе. 

**Что он умеет прямо сейчас:**
*   Создавать папки, файлы, перемещать их.
*   Выполнять сложные цепочки команд (например, `git init` -> создать файл -> сделать коммит).
*   Работать локально через **Ollama** или подключаться к облачным API (**OpenRouter**, **OpenCode**).
*   Иметь память и «мозгоподобную» архитектуру (лобная доля планирует, теменная — исполняет).

Это **Альфа-версия**. В ней работает ядро (200 автотестов пройдено!), но интерфейс (TUI) всё ещё кусается и иногда лагает.

## 🚀 Как запустить (Инструкция для тестера)

1. **Распакуй** папку `alpha` в любое удобное место.
2. **Установи Ollama** (если ещё нет): https://ollama.com
   *   После установки открой терминал (cmd/PowerShell) и скачай модель:
       `ollama pull qwen2.5-coder:7b`
3. **Запусти `ReshalaAI.Console.exe`** (рекомендую запускать от имени Администратора, чтобы не было проблем с правами).
   *   *Если Windows выдаст синее окно "Windows защитила ваш компьютер" — нажми "Подробнее" -> "Выполнить в любом случае". Это нормально для новых прог без платной подписи.*
4. Откроется красивый TUI-интерфейс.

## 🕹️ Как пользоваться (Команды и фишки)

Из-за того, что **TUI-интерфейс сейчас шалит (могут быть баги с вводом или скроллом)**, для стабильного тестирования я настоятельно рекомендую использовать режим **Admin**.

**Как войти в стабильный режим:**
Введи команду: `/admin` и нажми Enter. Ты попадешь в классический терминал, где всё работает четко.

**Основные команды (работают и в TUI, и в Admin):**
*   `/cloud` — показать список доступных облачных моделей. 
*   `/cloud set <цифра>` — выбрать облачную модель (например, `/cloud set 2`).
*   `/local` — показать список локальных моделей.
*   `/local set <цифра>` — выбрать локальную модель (например, `/local set 3`).
*   `/language en` (или `ru`) — переключить язык интерфейса.
*   `/admin` — перейти в режим чистого терминала (самый стабильный).
*   `/exit` — выйти из программы.

**Как давать задачи:**
Просто пиши обычным языком. Например: 
> *"Создай папку my_project на рабочем столе, зайди в нее и создай файл main.py"*
